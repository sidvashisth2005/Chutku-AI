## ⬇️ Download: **Chutku-Setup-for-Windows.exe**

This is the only file you need. It is the installer for **Windows 10 and 11 (64-bit)**. It does not run on Mac,
Linux, Android or iPhone. Ignore the "Source code" links below; GitHub adds them to every release.

1. Click **Chutku-Setup-for-Windows.exe** above to download it.
2. Open it. If Windows says **"Windows protected your PC"**, click **More info → Run anyway**. (Chutku is free and
   not signed with a paid certificate.)
3. Click **Install**. No administrator rights are needed.
4. Chutku opens a short setup: add your free AI key (one minute, Chutku shows you how) and you are ready.

Already using Chutku? It tells you about this update by itself: click **Update now** in the popup.

## What's new in 1.2.4

- **Spotify just works:** "play Lowkey playlist", "kesariya gaana chalao", "spotify pe Arijit ke gaane chalao". Your own
  playlists first; anything else through Spotify's search, and Chutku checks that the right music started. Much faster.
- **WhatsApp:** "is chat mein hello bhej do" sends to the chat you have open (works for Locked chats you opened);
  "open my chat" opens your own chat; first names like "Kritika" find the only matching chat; a new chat asks once,
  then never again.
- **Bluetooth:** "turn on bluetooth", "bluetooth band karo", "show bluetooth devices".
- **Shut down / restart:** "pc band karo" (5 minutes, asks first; "cancel shutdown" stops it).
- Misheard app names work ("Open sport" opens Spotify) and an app that is already open is brought to the front.
- Chit-chat gets a friendly answer instead of "please clarify".
- Saying "haan" a little late no longer fails with "approval expired".
- Closing the laptop lid no longer makes Chutku restart itself when it wakes up.
- **Smarter without internet:** the offline brain is now Qwen3.5-4B (faster and more accurate on Chutku's own tasks).
  Requests with several parts ("folder banao, usme file likho, phir files batao") are done one part at a time, so no
  part is skipped. Maths and logic questions get a few seconds of thinking ("2 ki power 10 aur 10 ka cube, kaun bada
  hai" is now right). If you already have the Offline brain, it keeps working; download it again from Settings to
  get the new model (about 5.3 GB in total).
- A folder you typed is never dropped from a path ("D:\Notes\work mein file banao" writes into `work`).
- "aaj Delhi ka mausam" gives Delhi's weather (it used to look up the wrong place); offline, the weather says there
  is no internet and the rest of a briefing still runs.
- "The playlist just below After Party" / "X ke neeche" picks the right item on the screen.
- Chutku never types into a password box, even after you approve; you type it and say continue.
- Work Chutku did and checked is never reported as failed, and you never see two Chutku windows at once.
